Política de privacidade do Tars

Última atualização: 11 de novembro de 2026

Quem usa

O Tars é um assistente pessoal privado. O único usuário é o seu proprietário, que autoriza o acesso à própria conta Google.

Quais dados são acessados

Somente os dados que o proprietário autoriza na tela de consentimento do Google, como eventos da Agenda Google. O acesso serve apenas para consultar compromissos, criar lembretes e organizar a agenda do próprio proprietário.

Onde os dados ficam

Os tokens de acesso ficam armazenados de forma criptografada no computador pessoal do proprietário. Os dados não são vendidos, compartilhados com terceiros nem usados para publicidade.

Uso de dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
